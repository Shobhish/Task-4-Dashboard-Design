# Task 4 - Dashboard Design

## Objective
Design an interactive dashboard for business stakeholders using Power BI.

## Tools Used
- Power BI
- PowerPoint

## Dataset
- Superstore Sales Dataset

## Dashboard Features
- KPI Cards (Sales, Profit, Orders, Growth)
- Sales Trend Analysis
- Sales by Region
- Sales by Category
- Sales by Segment
- Interactive Slicers / Filters

## Deliverables
- Interactive Dashboard (.pbix)
- Dashboard Screenshot
- PPT Summary

## Outcome
Built an interactive business dashboard to analyze sales performance and support data-driven decision making.
